# Bot System

All cars follow the closed racing path autonomously. Bot presets add pace, offset, personality, and adaptation variations. The player-team car follows the selected tyre, fuel, aero, and strategy configuration. This keeps racing readable while making setup consequences visible.

## One-click presets

- Rookie Grid: forgiving pace.
- Balanced Grid: recommended first race.
- Competitive Grid: faster opponents.
- Adaptive Rivals: behaviour changes after the weather decision.

Each selection updates the grid preview, and no driver-by-driver setup is required. Difficulty adjusts pace without changing the learning-event sequence.

Current limitation: Fill Empty Slots is represented by selecting a complete preset. Individual editing is deferred.
