# Tutorial Flow

Guided mode teaches the autonomous experiment loop:

1. Introduce the player as team principal.
2. State clearly that every car drives itself.
3. Choose a starting tyre, fuel load, and aero balance.
4. Read the Predictor’s expected lap and rain confidence.
5. Choose Scanner allocation and Adaptive Driver priority.
6. Launch the run.
7. Observe racing line and telemetry.
8. Use one high-level pace command.
9. Compare the Predictor, Scanner, and Adaptive Driver at the conflict.
10. Make the final strategy decision.
11. Review the debrief.
12. Change one setup value and rerun.

Quick Start shortens guidance. Free Lab keeps the mechanics and removes tutorial coaching. Copy avoids formulas and model-training jargon.
